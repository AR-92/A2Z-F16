# A2Z-F16

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

ITP A2Z Course for Fall 2016 - Course materials and assignments for the Algorithmic Art and Programming course.

## Description

This repository contains course materials, examples, and assignments for the ITP A2Z (Algorithmic Art and Programming) course offered in Fall 2016. The course focuses on creative coding, text processing, natural language processing, and generative art using JavaScript and other programming languages.

## Key Features

- Weekly course materials organized by topic
- In-class examples and exercises
- Assignments and projects
- Code samples for text processing and analysis
- Examples of creative coding and generative art
- Natural language processing techniques
- API integration examples

## Technologies Used

- **JavaScript**: Primary programming language
- **p5.js**: Creative coding library for visual art
- **Node.js**: Server-side JavaScript runtime
- **HTML/CSS**: Web technologies for presentation
- **APIs**: Integration with external services
- **Natural Language Processing**: Text analysis and generation
- **Regular Expressions**: Pattern matching and text manipulation

## Course Structure

The course is organized by weeks, with each week focusing on a different topic:

### Week 1: DOM Manipulation and String Processing
- Introduction to DOM manipulation with JavaScript
- String processing and manipulation techniques
- Basic text analysis

### Week 2: Regular Expressions
- Pattern matching with regular expressions
- Text validation and extraction
- Advanced regex techniques

### Week 3: APIs and Data
- Working with external APIs
- Data parsing and processing
- Closures and advanced JavaScript concepts

### Week 4: Node.js and Twitter API
- Server-side programming with Node.js
- Twitter API integration
- Social media data processing

### Week 5: Text Analysis
- Sentiment analysis
- Text classification
- Data visualization techniques

### Week 7: DOM Manipulation and Markov Chains
- Advanced DOM techniques
- Markov chain text generation
- Creative text processing

### Week 8: Context-Free Grammars
- Grammar-based text generation
- Rule-based systems
- Procedural content generation

### Week 9: Firebase and Node API
- Real-time database integration
- Building RESTful APIs with Node.js
- Cloud-based data storage

### Week 10: Chrome Extensions
- Browser extension development
- Content scripts and background processes
- User interface customization

### Week 11: Recurrent Neural Networks and LSTM
- Introduction to machine learning
- Text generation with neural networks
- LSTM implementation and usage

## Installation

```bash
# Clone the repository
git clone https://github.com/AR-92/A2Z-F16.git
cd A2Z-F16

# Most examples can be run directly in a browser
# For Node.js examples, install dependencies
npm install

# Start a local server for browser-based examples
python -m http.server 8000
```

## Usage

Each week's materials are contained in separate directories:
1. Navigate to the week you're interested in
2. Open the HTML files in a browser or run Node.js scripts
3. Follow the comments in the code for explanations
4. Experiment with the examples and modify them
